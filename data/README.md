# Data

Everything in `data/normalized/` is generated by the scripts in `etl/` from
pinned upstream sources (see `etl/sources.json`). Do not edit these files by
hand; fix the source or the script and regenerate.

| File | Source | Licence |
|---|---|---|
| `normalized/ce.jsonl` | GRETIL `sa_rAmAyaNa.xml` (Baroda Critical Edition; Tokunaga, J. Smith et al.) | [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) |
| `normalized/ce_report.json` | Structural anomalies found while parsing the above | same |

Each line of `ce.jsonl` is one verse:

```json
{"uid":"CE-1-001-001","gretil_id":"R_1.001.001","k":1,"s":1,"v":1,
 "lines":[["tapaḥsvādhyāyanirataṃ tapasvī vāgvidāṃ varam"],["nāradaṃ paripapraccha vālmīkir munipuṃgavam"]],
 "meter":"Anuṣṭubh"}
```

`lines` is the source IAST, NFC-normalised, one array per printed line; a
line with more than one element carries explicit pāda divisions from the
source (`<seg type="pāda">`). `meter` is computed (see `etl/meter.py`), and
is `null` when no listed metre fits.
